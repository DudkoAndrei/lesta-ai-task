## Использование

### Скрипт для перемножения матриц

Скрипт ``src/matrix_mul.py`` принимает 3 аргуметра: 2 файла с матрицами и имя файла, в который нужно сохранить результат перемножения
#### Пример
```bash
python2 src/matrix_mul.py example_data/matrix1.txt example_data/matrix2.txt result.txt
```

#### Формат данных
Файл с матрицей содержит 3 строки: количество строк, столбцов и элементы матрицы в построчном порядке

### Класс ``matrix_mul.Matrix``

#### 1. Создание
- ``Matrix(n, m)`` создаёт марцицу n*m с нулевыми элементами
- ``Matrix(n, m, [...])`` создаёт марцицу n*m с элементами из переданного спискаа. При несовпадени расмеров матрицы и списка и если в списке присутствуют элементы, не являющиеся числами, выдаёт ошибку ``ValueError``
#### 2. Поля класса:
- ``m.rows`` возвращает кол-во строк в матрице
- ``m.cols`` возвращает кол-во столбцов в матрице
- ``m.data`` возвращает список элементов матрицы в построчном порядке
#### 3. Методы класса:
- ``m.multiply(b)`` возвращает произведение матриц. При несоответствии размеров матриц выдаёт ``ValueError`` и при типк аргумента отличного от Matrix выдаёт ошибку ``TypeError``
- ``m.cols`` возвращает кол-во столбцов в матрице
- ``m == b, m != b`` возвращает результат сравнения матриц

## Тестирование

Для запуска тестов достаточно запустить ``pytest`` или ``tox``. Тесты находятся в директории ``tests``

## Ограничения

- Из операций доступно только умножение
- Нет возможности изменять элементы матрицы
- Нет возможности выбрать тип элементов матрицы (всегда используется double)
